# Deprecated: LunarVim module

This module is **deprecated**. Prefer the `nvim` module instead.

- Use `modules/nvim` for Neovim config and installation
- Install with: `install.sh nvim` or `install.sh --all`
- Launch with: `nvim`

The LunarVim installer here no longer installs LunarVim. Existing `lvim`
installs and `~/.config/lvim` overlays under this module are kept only for
reference / migration.
